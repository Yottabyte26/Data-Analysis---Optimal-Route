# Q02 机场路径规划代码审查报告

## 1. 项目整体评价

当前数据下，**三种算法的主目标均通过核验，现有 200 对 OD 的实验结果无需重算**。航空里程采用 CSV 原值，地面里程采用机场间大圆代理距离。BFS 的「最少中转」对应本项目的最少图边衔接次数。

审查读取了六个脚本、原始及清洗 CSV 和现有结果。使用独立的 NetworkX 有向多重图核对 600 条历史路径的最优目标值，并仅在内存中调用有代表性的路径和顺序敏感性检查。未执行任何会导出或覆盖历史结果的批处理入口。

## 2. 必须修复的问题

### P1｜构图入口允许缺失坐标变成有效里程

**位置**：[02_graph_builder.py:8](../scripts/02_graph_builder.py#L8)、[02_graph_builder.py:32](../scripts/02_graph_builder.py#L32)、[02_graph_builder.py:86](../scripts/02_graph_builder.py#L86)、[03_result_compare.py:437](../scripts/03_result_compare.py#L437)。

**证据**：直接调用现有 Haversine 函数，将其中一个纬度设为 NaN，返回 20,015.0868 km。原因是对 NaN 执行 `max(0, min(1, a))` 时中间量被夹成 1。构图入口也直接用机场 ID 写入坐标字典，重复 ID 可覆盖先前坐标。对比脚本先验证地面端点坐标，批量实验入口缺少同等保护。

**建议**：把机场主键唯一性和地面端点坐标的存在性、有限性及范围检查放在共享构图入口。先验证坐标，再对有效计算值做浮点边界夹取。

**现有 200 对 OD**：无影响。当前地面端点坐标合法，所有当前边权均为有限正数。异常输入会影响后续里程实验。

### P1｜批量构图未统一验证节点与边权

**位置**：[01_data_explore.py:702](../scripts/01_data_explore.py#L702)、[02_graph_builder.py:42](../scripts/02_graph_builder.py#L42)、[02_graph_builder.py:249](../scripts/02_graph_builder.py#L249)、[02_graph_builder.py:349](../scripts/02_graph_builder.py#L349)。

**证据**：清洗采用 `> 0`，正无穷也满足该条件。构图直接追加清洗表中的边，不验证目标节点或权重。Dijkstra 只显式跳过 None。NaN 参与松弛比较会静默失败，负权违反队列提前结束的前提，未知目标则可能使状态字典查找失败。现有构图断言检查的是总规模，无法覆盖这些输入问题。

**建议**：在统一的构图入口拒绝无效端点和非有限权重，按现行规则要求航空距离和两类耗时为正，并确保地面代理距离非负。提前校验 OD 端点属于图节点，把错误定位到文件和记录。搜索核心可保持现状。

**现有 200 对 OD**：无影响。已核验当前节点引用和全部 5,221 条边的两类权重。
